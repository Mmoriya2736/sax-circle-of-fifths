# 🎷 מעגל הקווינטות — מאמן סולמות וסימני היתק לנגני סקסופון

אפליקציית ווב נקייה, רספונסיבית ובעברית מלאה (RTL) במצב כהה לתרגול **מעגל הקווינטות**, זיהוי דיאזים ובמולים, וסולמות מז'ור ומינור מקבילים — מותאמת במיוחד לנגני סקסופון.

🔗 **כניסה לאפליקציה החיה:**
https://mmoriya2736.github.io/sax-circle-of-fifths/

---

## ✨ מה כולל המאמן?

### 1. שלושה סוגי שאלות (או הכל משולב)
- **זיהוי סולם לפי סימני היתק:** שאלות טקסט ברורות כמו *"מהו הסולם המז'ורי שיש בו 3 במולים (♭)?"* עם לוח כפתורים מלא (15 סולמות מז'ור / 15 סולמות מינור / 30 משולב, כולל אנהרמוניים).
- **זיהוי כמות דיאזים/במולים לפי שם הסולם:** שאלות הפוכות כמו *"כמה דיאזים או במולים יש בסולם E♭ מז'ור?"* עם לוח בחירה של 0, `1♯–7♯`, ו-`1♭–7♭`.
- **זיהוי חזותי על מעגל הקווינטות:** הדגשת פלח ריק בטבעת החיצונית (מז'ור) או הפנימית (מינור מקביל) על גבי תרשים SVG אינטראקטיבי.
- **הכל משולב (מומלץ):** ערבוב אוטומטי בין שלושת סוגי השאלות.

### 2. כלים ייעודיים לנגני סקסופון
- **תצוגת טרנספוזיציה לסקסופון:** הצגת הסולם המנוגן לאחר כל תשובה עבור **סקסופון אלט/בריטון (`E♭`)** או **סקסופון טנור/סופרן (`B♭`)**.
- **מיון כפתורים חכם:** ברירת מחדל ב**סדר כרומטי** (כדי שלא ניתן יהיה לנחש לפי המיקום במעגל), עם אפשרות מעבר לסדר מעגל הקווינטות.
- **שמות תווים בעברית:** מתג להצגת/הסתרת שמות התווים בעברית על הכפתורים (למשל `C / דו`, `Am / לה מינור`).
- **מעגל מלא וטבלת עזרה:** חלון עיון מהיר הכולל הן את מעגל הקווינטות המלא והן טבלת סולמות מסודרת.

### 3. למידה חכמה, סטטיסטיקות וסאונד
- **חזרה מחוזקת (Spaced Repetition):** סולמות שטעית בהם יופיעו בתדירות גבוהה יותר עד שתענה עליהם נכון פעמיים ברצף.
- **מעקב התקדמות מקומי (`localStorage`):** שמירת שיא רצף, אחוז הצלחה, זמן תגובה ממוצע וסולמות בחזרה מחוזקת — ללא צורך בשרת או הרשמה.
- **נגן מוזיקת רקע ללא פרסומות:** ניגון רציף של 5 קטעי סקסופון רומנטיים מקבצי MP3 מקומיים (`public/audio/track1.mp3` עד `track5.mp3`) עם שליטה בעוצמה ובמעבר בין שירים.
- **אפקטים קוליים (עידוד/בוז):** חיווי קולי מיידי לתשובה נכונה או שגויה עם מתג השתקה עצמאי.
- **מותאם למובייל (PWA-lite):** ניתן להוסיף למסך הבית בטלפון ולפתוח כמו אפליקציה עצמאית.

## 🛠️ הרצה מקומית (פיתוח)

```bash
npm install
npm run dev
```

לבניית גרסת הייצור הסטטית (`dist/`):

```bash
npm run build
```
